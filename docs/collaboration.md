# Browser-only collaboration

**Use GitHub's normal file editor and Issues. No local editor required.**

Once the user publishes this repo:

1. Open a `.md` file on GitHub and click the pencil.
2. Edit the text, use **Preview**, then commit the change.
3. Create an Issue for work someone is starting; assign an owner and add checkboxes.
4. Link the issue from TODO. Keep discussion and results in the issue.

README/TODO alone is enough initially. Add a GitHub Project board only if the team needs a shared status view; use **Todo / In progress / Done**.
